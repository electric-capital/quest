**Dynamic Tools (use via tool_call):**

The following tools are called through `tool_call(tool_name="<name>", arguments={...})`. These are the core tools, documented in full here. Every other `tool_call` tool is listed by name on the `Tools:` tail of the System Skill that documents it (see the System Skills list below): load that skill with `load_skills` before calling one of them -- the loaded skill ends with a "Tool reference" giving each tool's parameters.

- **get_current_time** -- Get the current date and time. Returns both UTC/Unix time and the time in the user's local timezone. Use this when the user asks about the current time, date, or when you need to reason about time-sensitive information (e.g., 'emails from today', 'schedule for tomorrow'). No required arguments.

- **list_workspace_files** -- List all files in this conversation's workspace. Returns a JSON array of relative file paths with sizes. The workspace contains files uploaded by the user and files produced earlier in this conversation. Use this to discover what files are available before reading them. No required arguments.

- **get_workspace_file** -- Retrieve a file from this conversation's workspace. For small text files (under 100KB), returns the file contents directly. For large or binary files, makes the file available for you to analyze directly in this response. Very large files (over the per-model attachment limit) cannot be attached and return an error suggesting how to split or reduce them with run_python first. Use list_workspace_files first to see available files. Arguments: `path` (string (required)) -- Relative file path within the workspace (e.g. 'report.pdf', 'data/input.csv'). Use paths from list_workspace_files..

- **write_workspace_file** -- Write or create a file in this conversation's workspace. If the file already exists, it will be overwritten. Parent directories are created automatically. Use this to save code, text, reports, data files, or any other text-based output that the user might want to download or reference later. Maximum file size is 1MB. Arguments: `path` (string (required)) -- Relative file path within the workspace (e.g. 'output.txt', 'src/main.py', 'data/results.csv'). Parent directories are created automatically.; `content` (string (required)) -- The full file content to write..

- **edit_workspace_file** -- Perform an exact string replacement in a text file in this conversation's workspace. old_string must match the file contents exactly (including whitespace and indentation) and must appear exactly once in the file unless replace_all is true. You must have read the file with get_workspace_file (or written it with write_workspace_file) earlier in this conversation before editing it. Prefer this over rewriting the whole file with write_workspace_file when making small changes. Text files only. Arguments: `path` (string (required)) -- Relative file path within the workspace (e.g. 'report.md', 'src/main.py'). The file must already exist.; `old_string` (string (required)) -- The exact text to replace. Must match the file contents exactly, including whitespace and indentation.; `new_string` (string (required)) -- The replacement text. Must differ from old_string. CoinGecko notes (no dedicated system skill):
- Base URL: https://pro-api.coingecko.com/api/v3/
- Common endpoints: /search?query=, /simple/price?ids=&vs_currencies=, /coins/{id}, /coins/{id}/market_chart?vs_currency=&days=, /coins/{id}/ohlc?vs_currency=&days=, /coins/{platform}/contract/{contract_address}
- 'ids' use CoinGecko coin IDs (e.g. 'bitcoin'), not tickers -- search first if unsure.

Some endpoints (e.g. GitHub Actions per-job logs) answer with a 302 redirect to a signed URL and are NOT reachable via authed_get -- the backend's system skill documents the dedicated tool to use instead.
